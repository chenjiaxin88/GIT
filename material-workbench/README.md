# 素材工作台

素材工作台给视频制作人员提供一个固定入口。员工首次用负责人发的个人链接激活，以后打开同一网址就能查看自己的任务，取用参考图、图片提示词、分段视频提示词和原片。

[打开在线演示](https://chenjiaxin88.github.io/GIT/material-workbench/)

在线演示用两套虚构任务展示员工视角，可以切换示例身份、查看分配给该身份的任务和复制提示词。它是公开页面。正式登录与按人授权由内网的 Node.js 员工站提供。 浏览器会使用设备已安装的 Anthropic Sans 渲染拉丁字符，中文使用系统字体。

## 目录

| 文件 | 用途 |
| --- | --- |
| `demo/index.html` | GitHub Pages 演示页，直接在浏览器打开 |
| `server.mjs` | 员工站，负责激活、会话、按人读取资料及原片播放 |
| `native-office-tls.mjs` | 使用内网可信证书直接提供 HTTPS |
| `windows/` | 本机启动、签发和撤销员工访问 |
| `server.test.mjs` | 用合成数据测试登录、权限隔离、视频分段读取和撤销 |

## 在 Windows 主机上启动

1. 准备 Node.js 24。将本目录放在主机的非共享目录，从内部交付包复制 `snapshot/` 到该目录，确认同级可见 `server.mjs`、`windows/` 和 `snapshot/snapshot.json`。也可直接在已解压的内部交付包使用下列脚本。
2. 双击 `windows/启动员工站.cmd`，选 **1**，在主机的浏览器打开 `http://127.0.0.1:8791/` 试用。
3. 拿到公司内网 HTTPS 网址后，重新打开启动脚本，输入 **S** 停止试用，再按实际接入方式配置。使用本机托管时，办公时段保持主机接电和联网。

| 接入方式 | 启动选项 | 配置 |
| --- | --- | --- |
| 已有能够转发到本机的公司 HTTPS 代理 | **2** | 填写公司网址。同机代理转发至 `127.0.0.1:8791`，传递原始 `Host`、`Origin` 及视频 `Range` 请求。独立网关需与 IT 确认它到主机的转发链路。 |
| 本机直接提供公司 HTTPS | **3** | 准备固定办公网 IP、内网 DNS 名称和员工设备信任的匹配 PFX 证书。按提示填写网址、IP 和证书路径，口令在本机输入。 |

用第二台办公设备打开正式网址，查看登录页和证书信任状态。负责人随后双击 `windows/签发员工链接.cmd`，按人私发一次性链接。首次激活期限是 24 小时，登录会话有效期是 7 天。员工激活后收藏同一个公司网址。人员变更或误发时可用 `windows/撤销员工访问.cmd` 单独撤销。

真实名单、任务快照、图词、原片、登录状态和证书均存放在授权的办公主机。登录状态由启动程序保存到项目目录旁边的本机状态目录。员工浏览器通过 HTTPS 访问按人授权的资料。

## 自测

```powershell
node --test .\server.test.mjs
```

自测会生成临时虚构账号和样例数据。验证包括一次性链接、跨员工资料隔离、退出、撤销和视频分段读取。
